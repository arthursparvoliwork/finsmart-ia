## 📖 Sobre o Projeto

O **FinSmart IA** é uma aplicação web full-stack que ajuda usuários a entenderem seus gastos de forma inteligente. O usuário cadastra suas transações e o sistema:

- 🤖 **Categoriza automaticamente** as transações usando Machine Learning (Scikit-Learn)
- 🔍 **Detecta gastos suspeitos** (anomalias) com Deep Learning (TensorFlow)
- 💬 **Responde perguntas** em linguagem natural via chat com IA (LangChain)
- 📊 **Visualiza tudo** em dashboards interativos e animados
- 🔐 **Protege os dados** com autenticação JWT

## 🛠️ Stack Tecnológica

### Backend (Python)
| Tecnologia | Função |
|------------|--------|
| **Flask** | API REST |
| **SQLAlchemy + SQLite** | Banco de dados |
| **Pydantic** | Validação de dados |
| **JWT (PyJWT)** | Autenticação segura |
| **Scikit-Learn** | Categorização (ML clássico) |
| **TensorFlow** | Detecção de anomalias (Deep Learning) |
| **LangChain** | Chat com IA |

### Frontend (JavaScript)
| Tecnologia | Função |
|------------|--------|
| **React** | Biblioteca de UI |
| **Tailwind CSS** | Estilização |
| **Kokonut UI** | Componentes prontos |
| **Three.js** | Visual 3D |
| **GSAP** | Animações |
| **Recharts** | Gráficos |

### Princípios e Boas Práticas
- 🏛️ **SOLID** aplicado no design do código
- 🧪 **Testes** (pytest + Jest)
- 🎨 **Design** no Figma + Bklit Studio
